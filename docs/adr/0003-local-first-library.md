# The Library is local-first

Every device keeps a full copy of the Library. Reading, Playback and Corrections work with no connection, and changes sync when the device is back online. Only Conversion and Source search need the server. We chose this over a server-first app because the tablet is used on a music stand during practice, lessons and performances, where losing the connection must never interrupt the music. The cost is that sync has to merge edits made on different devices, and that cost is far lower if we design for it now than if we add offline support later.
