# IMSLP is a search-only Source

The app searches IMSLP's catalog but never downloads IMSLP files itself. The user downloads them on IMSLP's own site and then Imports them. IMSLP deliberately blocks scripted downloads behind a bot check, and we will not try to get around it, so do not "improve" this by automating IMSLP downloads. One-tap download into the Library is reserved for Sources whose terms allow it, such as OpenScore (CC0) and Mutopia.
